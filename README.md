# 💫 About Me:
Systems engineer focused primarily on backend development, with Go as my main language. I’m currently building a startup: a CRM for freelancers, built on a microservices architecture. It combines a core Go service for CRM, project management and invoicing with an independent security-scanner service. The project doesn’t have a name yet, but the repository is already public on my GitHub. I also have frontend experience with TypeScript, React and Tailwind CSS, which lets me work on a product end to end
